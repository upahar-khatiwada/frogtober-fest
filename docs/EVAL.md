## How to read this

- Scout: 15 hand-labelled synthetic notices (`data/golden/scout_expected.json`). One notice is 6.7 points, so small gaps between models are noise. A `null` label counts as correct only if Scout also returns null.
- Matching and Compliance run on **oracle records** (hand-labelled facts), so they do not include Scout errors. Compliance's Layer 1 is deterministic code and identical across models; only the model layer (licence class, personnel, equipment, ...) changes with the model.
- Compliance hard-fail recall is the number to watch: a missed hard fail means a bid that will be disqualified goes ahead.
- The notices and the demo company are synthetic and the labels were written by the project team from the same text. These numbers show the plumbing and relative model behaviour; they are not an estimate of accuracy on real notices.
- `n/a` means the stage was not run (offline mode, or the model call failed; see Errors).
